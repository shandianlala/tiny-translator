# Tiny Translator 隐私政策

**最后更新：2026-09-06**

Tiny Translator 是一个精简的划词查词 Chrome 扩展（Manifest V3）。本政策说明扩展会接触哪些数据、如何处理这些数据。本政策仅适用于本扩展，不适用于有道等第三方服务。

## 我们收集的信息

本扩展**不收集任何个人信息、不读取浏览历史、不上传完整网页内容**。它可能接触的数据仅限以下三类，且全部由你主动触发：

1. **你选中并查询的单词**

   当你在网页上**选中一个纯英文单词并点击查询角标**后，该单词字符串会被发送给有道词典（`dict.youdao.com`），用于返回该词的音标、中文释义和常用词组。

   - 在你点击查询之前，不会发送任何数据。
   - 只会发送你选中的那一个单词本身，不包含它所在的句子、上下文或网页内容。
   - 非英文的多词选区、短语、句子、中文、数字不会触发任何请求。

2. **你点击播放发音时的同一个单词**

   当你点击卡片上的音标来播放发音时，同一个单词会被发送给有道发音接口（`dict.youdao.com/dictvoice`）。同样仅在你主动点击后发生。

3. **你主动收藏的内容（仅存本机）**

   收藏记录（单词及其查词结果快照、收藏时间）**只保存在你本机浏览器的本地存储**（`chrome.storage.local`）中，**不会上传到任何服务器**。卸载扩展或清除浏览器数据即会删除。列表中的“导出 JSON”会把收藏下载到你自己的电脑上，也是由你主动点击触发的本地文件下载。

## 我们不收集的信息

- 浏览历史、完整网页内容、打开的标签页
- 账号信息、Cookie、登录凭据
- 位置、设备指纹、IP 归属等设备/网络信息
- 任何广告、分析、行为追踪（本扩展无任何分析或追踪 SDK）

## 第三方共享

- **唯一的数据接收方是有道（Youdao，`dict.youdao.com`）。** 如上所述，仅在你主动查词或点发音时，才会把你选中的单词发送给有道。有道的服务与数据处理由其自身的[隐私与条款](https://www.youdao.com)约束。
- 除上述外，本扩展不向任何其他第三方传输、出售或共享数据。

## 权限说明

| 权限 / 声明 | 用途 |
|---|---|
| `storage` | 仅用于在你本机保存收藏记录 |
| 内容脚本运行于所有网页 | 仅用于监听鼠标划词（只响应“单个纯英文单词”的选区），不读取或上传页面内容 |
| 对 `dict.youdao.com` 的网络请求 | 仅用于查询词典数据和播放发音 |

## 数据保留与删除

- 收藏数据保存在你本机，直到你手动删除、卸载扩展或清除浏览器数据。
- 我们（开发者）不运行任何服务器，不保留、不查看你的任何数据。
- 扩展不含远程代码，全部功能均在本地运行。

## 政策更新

若本扩展的数据处理方式发生变化，本页面会随之更新并修改“最后更新”日期。
